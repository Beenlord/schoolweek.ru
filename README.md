# SHOOLWeek

Школьный дневник это гениальное изобретение! Им было удобно пользоваться в школе, некоторые продолжают им пользоваться в вузе, а мы решили создать электронную версию такого дневника для обычной жизни. Наш дневник сочетает в себе ностальгические нотки школьного прошлого, а так же простоту и гениальность расписания всё в одном и концепцию неделя на одном листе.
